# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-21
### Added
- Fully playable 3D chess environment set under a tree.
- Player vs Player mode with dynamic Bezier curve camera rotation.
- Player vs AI mode powered by Stockfish Web Worker (4 difficulty levels).
- Interactive 3D pieces with lift, slide, and lower animations.
- Optional game timers (Blitz, Rapid, Classical).
- Interactive pawn promotion modal.
- Post-game review mode enabling timeline scrubbing with stable piece tracking.
- Captured pieces graveyard that accurately tracks history during review mode.
- Wooden aesthetic UI panels and controls.
